## 使用場景

### 場景 1: 每日訂單處理
```
原始數據 → 讀取 → 驗證 → 清洗 → 轉換 → 品質檢查 → 資料庫 → 報告 → 通知
```

### 場景 2: 多來源資料同步
```
來源1 (CSV) ─┐
來源2 (API)  ├→ 提取 → 對應 → 去重 → 衝突解決 → 整合 → 輸出
來源3 (DB)  ─┘
```

### 場景 3: 實時數據監控
```
數據流入 → 驗證 → 品質檢查 → 性能監控 → 告警 → 通知管理員
```

### 場景 4: 自動化報告
```
定時任務 → ETL → 品質檢查 → 數據聚合 → 報告生成 → 郵件/Slack
```

## 已知限制

1. **資料庫**: 當前主要支援 SQLite，生產環境建議使用 PostgreSQL
2. **並發**: 單線程設計，高併發場景需要進一步優化
3. **分布式**: 不支援分布式執行，需要外部調度框架
4. **實時性**: 批處理設計，不支援實時流處理
