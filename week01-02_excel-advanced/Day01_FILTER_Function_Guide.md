## 📚 Part 1: 動態陣列基礎（30 分鐘）

### 什麼是動態陣列？

**傳統公式：**
```excel
=A1*2
```
- 結果：只有一個值
- 如果要應用到多個儲存格，需要「向下拖曳」或「複製公式」

**動態陣列公式：**
```excel
=A1:A10*2
```
- 結果：自動溢出到 10 個儲存格
- 不需要拖曳，自動填滿

### #SPILL! 錯誤

當動態陣列的「溢出範圍」被其他內容佔用時，會出現 `#SPILL!` 錯誤。

**解決方法：**
1. 清空溢出範圍的儲存格
2. 選擇其他位置放置公式

### 動態陣列的優勢

1. **自動更新**：來源資料改變，結果自動更新
2. **單一公式**：不需要複製到多個儲存格
3. **易於維護**：只需修改一個公式

## 📖 Part 2: FILTER() 基礎語法（30 分鐘）

### 語法

```excel
=FILTER(array, include, [if_empty])
```

**參數說明：**
- `array`：要篩選的資料範圍
- `include`：篩選條件（返回 TRUE/FALSE 的陣列）
- `[if_empty]`：（可選）當沒有符合條件的資料時，顯示的訊息

## 💡 Part 3: 實戰練習（2 小時）

### 練習 1：單條件篩選（15 分鐘）

**情境：** 篩選出「已完成」的訂單

**資料表：** `case01_realistic_sales_data.xlsx` → 訂單明細

**步驟：**

1. 開啟 Excel 檔案
2. 在新的工作表中，輸入以下公式：

```excel
=FILTER(訂單明細!A2:AN1001, 訂單明細!D2:D1001="已完成", "查無已完成訂單")
```

**解釋：**
- `訂單明細!A2:AN1001`：要篩選的資料範圍（所有訂單資料）
- `訂單明細!D2:D1001="已完成"`：條件（訂單狀態欄位 = "已完成"）
- `"查無已完成訂單"`：如果沒有結果，顯示此訊息

**預期結果：**
- 自動列出所有「已完成」的訂單
- 包含所有 40 個欄位

**練習變化：**
試試看篩選其他狀態：
```excel
=FILTER(訂單明細!A2:AN1001, 訂單明細!D2:D1001="配送中")
=FILTER(訂單明細!A2:AN1001, 訂單明細!D2:D1001="處理中")
```

---

### 練習 2：數值條件篩選（15 分鐘）

**情境：** 篩選出「訂單總額 > 5000」的訂單

**公式：**

```excel
=FILTER(訂單明細!A2:AN1001, 訂單明細!AB2:AB1001>5000, "查無大額訂單")
```

**解釋：**
- `訂單明細!AB2:AB1001>5000`：訂單總額欄位 > 5000

**練習變化：**
```excel
// 訂單總額在 3000-10000 之間
=FILTER(訂單明細!A2:AN1001, (訂單明細!AB2:AB1001>=3000)*(訂單明細!AB2:AB1001<=10000))

// 訂單總額 >= 10000
=FILTER(訂單明細!A2:AN1001, 訂單明細!AB2:AB1001>=10000)
```

---

### 練習 3：多條件篩選（AND 邏輯）（20 分鐘）

**情境：** 篩選「已完成」且「訂單總額 > 5000」的訂單

**公式：**

```excel
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!D2:D1001="已完成") * (訂單明細!AB2:AB1001>5000),
    "查無符合條件的訂單"
)
```

**解釋：**
- `*` 代表 AND（且）邏輯
- 兩個條件都要 TRUE，結果才是 TRUE

**練習變化：**

**範例 A：三條件篩選**
```excel
// 已完成 + 總額>5000 + 北部地區
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!D2:D1001="已完成") *
    (訂單明細!AB2:AB1001>5000) *
    (訂單明細!AN2:AN1001="北部")
)
```

**範例 B：會員等級 + 金額篩選**
```excel
// 鑽石會員 + 總額>3000
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!K2:K1001="鑽石") *
    (訂單明細!AB2:AB1001>3000)
)
```

---

### 練習 4：多條件篩選（OR 邏輯）（20 分鐘）

**情境：** 篩選「產品類別是電腦周邊」或「產品類別是手機配件」的訂單

**公式：**

```excel
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!N2:N1001="電腦周邊") + (訂單明細!N2:N1001="手機配件"),
    "查無符合條件的訂單"
)
```

**解釋：**
- `+` 代表 OR（或）邏輯
- 任一條件為 TRUE，結果就是 TRUE

**練習變化：**

**範例 A：三個產品類別**
```excel
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!N2:N1001="電腦周邊") +
    (訂單明細!N2:N1001="手機配件") +
    (訂單明細!N2:N1001="家電")
)
```

**範例 B：狀態篩選（排除某些狀態）**
```excel
// 篩選「配送中」或「處理中」的訂單
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!D2:D1001="配送中") + (訂單明細!D2:D1001="處理中")
)
```

---

### 練習 5：日期範圍篩選（20 分鐘）

**情境：** 篩選「2024年11月」的訂單

**公式：**

```excel
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!B2:B1001>=DATE(2024,11,1)) *
    (訂單明細!B2:B1001<=DATE(2024,11,30)),
    "查無本月訂單"
)
```

**解釋：**
- `DATE(2024,11,1)`：建立日期（2024年11月1日）
- `>=` 和 `<=` 構成範圍條件

**練習變化：**

**範例 A：本週訂單**
```excel
// 假設今天是 2024-11-15（週五）
// 本週一 = 2024-11-11
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!B2:B1001>=DATE(2024,11,11)) *
    (訂單明細!B2:B1001<=DATE(2024,11,15))
)
```

**範例 B：最近 30 天**
```excel
=FILTER(
    訂單明細!A2:AN1001,
    訂單明細!B2:B1001>=TODAY()-30
)
```

**範例 C：特定月份（多月）**
```excel
// 2024年 10月 或 11月
=FILTER(
    訂單明細!A2:AN1001,
    ((訂單明細!B2:B1001>=DATE(2024,10,1)) * (訂單明細!B2:B1001<=DATE(2024,10,31))) +
    ((訂單明細!B2:B1001>=DATE(2024,11,1)) * (訂單明細!B2:B1001<=DATE(2024,11,30)))
)
```

### 練習 6：組合條件（AND + OR）（30 分鐘）

**情境：** 篩選「（電腦周邊 或 手機配件）且 總額>3000」的訂單

**公式：**

```excel
=FILTER(
    訂單明細!A2:AN1001,
    ((訂單明細!N2:N1001="電腦周邊") + (訂單明細!N2:N1001="手機配件")) *
    (訂單明細!AB2:AB1001>3000)
)
```

**解釋：**
- 先用 `+` 處理 OR 條件（用括號括起來）
- 再用 `*` 與其他條件做 AND

**練習變化：**

**範例 A：複雜組合**
```excel
// (鑽石會員 或 黃金會員) 且 (總額>5000) 且 (已完成)
=FILTER(
    訂單明細!A2:AN1001,
    ((訂單明細!K2:K1001="鑽石") + (訂單明細!K2:K1001="黃金")) *
    (訂單明細!AB2:AB1001>5000) *
    (訂單明細!D2:D1001="已完成")
)
```

**範例 B：地區 + 類別 + 金額**
```excel
// (北部 或 中部) 且 (電腦周邊 或 家電) 且 (總額>2000)
=FILTER(
    訂單明細!A2:AN1001,
    ((訂單明細!AN2:AN1001="北部") + (訂單明細!AN2:AN1001="中部")) *
    ((訂單明細!N2:N1001="電腦周邊") + (訂單明細!N2:N1001="家電")) *
    (訂單明細!AB2:AB1001>2000)
)
```

### 練習 7：文字條件（包含/不包含）（15 分鐘）

**情境：** 篩選「產品名稱包含 Apple」的訂單

**需要搭配其他函數：**

```excel
=FILTER(
    訂單明細!A2:AN1001,
    ISNUMBER(SEARCH("Apple", 訂單明細!O2:O1001))
)
```

**解釋：**
- `SEARCH("Apple", 訂單明細!O2:O1001)`：在產品名稱中搜尋 "Apple"
- 找到會返回位置（數字），找不到返回 #VALUE!
- `ISNUMBER(...)`：將結果轉成 TRUE/FALSE

**練習變化：**

**範例 A：客戶名稱包含「王」**
```excel
=FILTER(
    訂單明細!A2:AN1001,
    ISNUMBER(SEARCH("王", 訂單明細!F2:F1001))
)
```

**範例 B：地址包含「台北」**
```excel
=FILTER(
    訂單明細!A2:AN1001,
    ISNUMBER(SEARCH("台北", 訂單明細!L2:L1001))
)
```

## 🔥 Part 4: 進階應用（30 分鐘）

### 進階 1：只返回特定欄位

**情境：** 只顯示「訂單編號、客戶姓名、產品名稱、訂單總額」

**公式：**

```excel
=FILTER(
    訂單明細!A2:A1001 & "," & 訂單明細!F2:F1001 & "," &
    訂單明細!O2:O1001 & "," & 訂單明細!AB2:AB1001,
    訂單明細!D2:D1001="已完成"
)
```

**更好的方式（使用 CHOOSECOLS）：**

```excel
=CHOOSECOLS(
    FILTER(訂單明細!A2:AN1001, 訂單明細!D2:D1001="已完成"),
    1, 6, 15, 27
)
```

**解釋：**
- `CHOOSECOLS(array, col1, col2, ...)`：選擇特定欄位
- `1, 6, 15, 27` 對應：訂單編號、客戶姓名、產品名稱、訂單總額

---

### 進階 2：巢狀 FILTER

**情境：** 先篩選「已完成」，再篩選「總額>5000」

**公式：**

```excel
=FILTER(
    FILTER(訂單明細!A2:AN1001, 訂單明細!D2:D1001="已完成"),
    CHOOSECOLS(FILTER(訂單明細!A2:AN1001, 訂單明細!D2:D1001="已完成"), 27)>5000
)
```

**注意：** 通常直接用多條件 `*` 更簡潔

---

### 進階 3：動態條件（使用儲存格）

**情境：** 在 A1 儲存格輸入產品類別，自動篩選

**設定：**
- A1 儲存格：輸入「電腦周邊」

**公式（在 A3）：**

```excel
=FILTER(
    訂單明細!A2:AN1001,
    訂單明細!N2:N1001=A1,
    "查無 " & A1 & " 類別的訂單"
)
```

**使用方式：**
1. 修改 A1 的值（例如改成「手機配件」）
2. 篩選結果自動更新

### 作業 1：建立動態訂單查詢系統

在新工作表中建立以下系統：

**介面設計：**
```
A1: 產品類別     B1: [下拉選單: 電腦周邊/手機配件/...]
A2: 訂單狀態     B2: [下拉選單: 全部/已完成/配送中/...]
A3: 最低金額     B3: [輸入框: 0]
A4: 最高金額     B4: [輸入框: 999999]

A6: [篩選結果從這裡開始]
```

**公式（A6）：**

```excel
=LET(
    全部訂單, 訂單明細!A2:AN1001,
    產品條件, IF(B1="全部", TRUE, 訂單明細!N2:N1001=B1),
    狀態條件, IF(B2="全部", TRUE, 訂單明細!D2:D1001=B2),
    金額條件, (訂單明細!AB2:AB1001>=B3) * (訂單明細!AB2:AB1001<=B4),
    FILTER(全部訂單, 產品條件 * 狀態條件 * 金額條件, "查無符合條件的訂單")
)
```

**測試：**
1. 選擇「電腦周邊」+「已完成」+「金額 3000-10000」
2. 觀察結果是否正確
3. 嘗試不同組合

## 💡 常見問題

**Q1: 為什麼我的公式出現 #SPILL! 錯誤？**
A: 檢查公式下方和右方的儲存格是否有內容，清空它們即可。

**Q2: 可以篩選多個工作表嗎？**
A: 不能直接篩選，但可以先用其他方式合併工作表，再篩選。

**Q3: FILTER 的效能如何？**
A: 對於 10 萬筆以下的資料，效能很好。超過 10 萬筆建議使用 Power Query 或 Python。

**Q4: 條件太複雜，公式太長怎麼辦？**
A: 使用 LET() 函數（Day 4 會學）可以大幅簡化複雜公式。
