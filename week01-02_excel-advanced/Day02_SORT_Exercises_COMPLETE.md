## 🎯 SORT vs SORTBY 函數對比

### **SORT 函數**
```excel
=SORT(array, [sort_index], [sort_order], [by_col])
```

**特點：**
- 依照「結果資料本身的欄位」排序
- 適合：資料中已包含排序依據
- 例如：依照資料中的金額欄排序

### **SORTBY 函數**
```excel
=SORTBY(array, by_array1, [sort_order1], [by_array2], [sort_order2], ...)
```

**特點：**
- 依照「外部欄位」排序
- 適合：根據其他欄位排序，但不想顯示該欄位
- 例如：依照金額排序，但結果不顯示金額欄

## 🎯 練習題系統

### **基礎練習（30 分鐘）**

#### **練習 1：單欄位升序排序**

**題目：** 將所有訂單按「訂單總額」由小到大排序

**Excel 公式：**
```excel
=SORT(訂單明細!A2:AN1001, 28, 1)
```

**參數說明：**
- `A2:AN1001` - 要排序的資料範圍
- `28` - 第 28 欄（AB 欄 = 訂單總額）
- `1` - 升序（1=升序，-1=降序）

**Python 對照：**
```python
df.sort_values('訂單總額', ascending=True)
```

**預期結果：**
- 最小金額訂單在最上方
- 金額逐漸增加
- 檢查：AB 欄數值應該是遞增的

**小提示：**
如何算出欄位位置？
- A=1, B=2, C=3... Z=26
- AA=27, AB=28, AC=29...
- 或直接數：從 A 數到 AB 是第 28 個

---

#### **練習 2：單欄位降序排序**

**題目：** 將所有訂單按「訂單總額」由大到小排序

**Excel 公式：**
```excel
=SORT(訂單明細!A2:AN1001, 28, -1)
```

**參數說明：**
- `-1` - 降序（由大到小）

**Python 對照：**
```python
df.sort_values('訂單總額', ascending=False)
```

**預期結果：**
- 最大金額訂單在最上方
- 通常是高單價 3C 產品
- 金額 > 20,000 的訂單

**實用場景：**
- 找出高價值訂單
- 識別 VIP 客戶
- 分析大額交易模式

#### **練習 3：按日期排序**

**題目：** 將訂單按「訂單日期」從最新到最舊排序

**Excel 公式：**
```excel
=SORT(訂單明細!A2:AN1001, 2, -1)
```

**參數說明：**
- `2` - 第 2 欄（B 欄 = 訂單日期）
- `-1` - 降序（最新日期在上）

**Python 對照：**

**預期結果：**

#### **練習 4：多欄位排序**

**題目：** 先按「產品類別」排序，同類別內再按「訂單總額」降序排序

**Excel 公式：**
```excel
=SORT(訂單明細!A2:AN1001, {14, 28}, {1, -1})
```

**參數說明：**
- `{14, 28}` - 陣列：第 14 欄（類別）和第 28 欄（金額）
- `{1, -1}` - 陣列：第一欄升序，第二欄降序

**Python 對照：**
```python
df.sort_values(['產品類別', '訂單總額'], ascending=[True, False])
```

**公式解析：**
1. **{}** - 大括號建立陣列
2. 先按類別升序排列
3. 同類別內，按金額降序排列
4. 這樣可以看到每個類別中的高金額訂單

#### **練習 6：SORTBY 基礎應用**

**題目：** 只顯示「訂單編號、客戶ID、產品名稱」，但按「訂單總額」降序排列

**為什麼用 SORTBY？**
- 我們想依照「訂單總額」排序
- 但結果中「不想顯示訂單總額欄位」
- SORTBY 可以依照外部欄位排序

**Excel 公式：**
```excel
=SORTBY(
    CHOOSECOLS(訂單明細!A2:AN1001, 1, 3, 15),
    訂單明細!AB2:AB1001,
    -1
)
```

**或使用簡化版（直接選欄位）：**
```excel
=SORTBY(
    訂單明細!A2:C1001,
    訂單明細!AB2:AB1001,
    -1
)
```

**參數說明：**
- 第一個參數：要顯示的資料（訂單編號、客戶ID、產品名稱）
- 第二個參數：排序依據（訂單總額）
- 第三個參數：降序

**Python 對照：**
```python
df[['訂單編號', '客戶ID', '產品名稱']].sort_values(
    by='訂單總額',  # 注意：這裡 pandas 無法直接做到，需要先排序再選欄
    ascending=False
)

# 正確做法：
df.sort_values('訂單總額', ascending=False)[['訂單編號', '客戶ID', '產品名稱']]
```

**預期結果：**
- 只看到 3 個欄位
- 但順序是按金額排列的
- 高金額訂單在最上方

---

#### **練習 7：SORTBY 多欄位排序**

**題目：** 顯示「產品名稱、數量」，按「類別」升序，同類別內按「單價」降序排列

**Excel 公式：**
```excel
=SORTBY(
    CHOOSECOLS(訂單明細!A2:AN1001, 15, 17),
    訂單明細!N2:N1001, 1,
    訂單明細!P2:P1001, -1
)
```

**參數說明：**
- `CHOOSECOLS(..., 15, 17)` - 選第 15 欄（產品名稱）和第 17 欄（數量）
- `N2:N1001, 1` - 第一排序依據：類別（升序）
- `P2:P1001, -1` - 第二排序依據：單價（降序）

**Python 對照：**
```python
df.sort_values(['產品類別', '單價'], ascending=[True, False])[['產品名稱', '數量']]
```

### **高階挑戰（60 分鐘）**

#### **練習 8：FILTER + SORT 組合**

**題目：** 篩選出「已完成」的訂單，並按「訂單總額」降序排列

**Excel 公式：**
```excel
=SORT(
    FILTER(訂單明細!A2:AN1001, 訂單明細!D2:D1001="已完成"),
    28, -1
)
```

**Python 對照：**
```python
df[df['訂單狀態'] == '已完成'].sort_values('訂單總額', ascending=False)
```

**公式解析（由內而外）：**
1. `FILTER()` - 先篩選出已完成訂單
2. `SORT()` - 再對篩選結果排序
3. `28, -1` - 按第 28 欄降序

**實用場景：**
- 查看已完成的大額訂單
- 分析高價值交易
- 識別重要客戶

#### **練習 9：Top N 查詢（TAKE 函數）**

**題目：** 找出訂單金額最高的前 10 筆訂單

**Excel 公式：**
```excel
=TAKE(
    SORT(訂單明細!A2:AN1001, 28, -1),
    10
)
```

**Python 對照：**
```python
df.sort_values('訂單總額', ascending=False).head(10)
```

**公式解析：**
1. `SORT(..., 28, -1)` - 按金額降序排列
2. `TAKE(..., 10)` - 取前 10 筆

**TAKE 函數說明：**
```excel
=TAKE(array, rows, [columns])
```
- `rows` - 取幾列（正數從頭取，負數從尾取）
- `columns` - 取幾欄（選填）

**變化練習：**
```excel
// 取最後 5 筆（金額最低的 5 筆）
=TAKE(SORT(..., 28, -1), -5)

// 也可以用 DROP 跳過前面，取後面的
=DROP(SORT(..., 28, -1), 995)  // 跳過前 995 筆，取最後 5 筆
```

#### **練習 10：每個類別的 Top 5**

**題目：** 找出每個產品類別中訂單金額最高的 5 筆訂單

**這題比較複雜，需要分類別處理**

**方法 1：使用多個公式（推薦初學）**

```excel
// 先篩選該類別，再排序，再取前 5
// 例如：電腦周邊 Top 5
=TAKE(
    SORT(
        FILTER(訂單明細!A2:AN1001, 訂單明細!N2:N1001="電腦周邊"),
        28, -1
    ),
    5
)
```

對每個類別重複這個操作。

**方法 2：使用 LET + LAMBDA（進階）**

這需要較複雜的技巧，先掌握方法 1 即可。

**Python 對照：**
```python
# 簡單！
df.groupby('產品類別').apply(
    lambda x: x.nlargest(5, '訂單總額')
).reset_index(drop=True)
```

#### **練習 11：條件 Top N**

**題目：** 找出「已完成訂單」中「電腦周邊類別」的前 10 大訂單

**Excel 公式：**
```excel
=TAKE(
    SORT(
        FILTER(
            訂單明細!A2:AN1001,
            (訂單明細!D2:D1001="已完成") *
            (訂單明細!N2:N1001="電腦周邊")
        ),
        28, -1
    ),
    10
)
```

**Python 對照：**
```python
df[
    (df['訂單狀態'] == '已完成') &
    (df['產品類別'] == '電腦周邊')
].nlargest(10, '訂單總額')
```

**公式解析（3 層嵌套）：**
1. **最內層 FILTER** - 篩選「已完成 + 電腦周邊」
2. **中間層 SORT** - 按金額降序排列
3. **最外層 TAKE** - 取前 10 筆

**小提示：**
- 從內而外思考
- 先篩選 → 再排序 → 最後取 N 筆
- 就像搭積木一樣層層堆疊

#### **練習 12：Bottom N 查詢**

**題目：** 找出訂單金額最低的 10 筆訂單

**方法 1：使用 TAKE 負數**
```excel

```

**方法 2：直接升序排列**



### **實戰專案（90 分鐘）**

#### **專案：動態 Top N 排行榜系統**

**需求說明：**
建立一個可以動態調整的排行榜系統

**功能要求：**
1. 可選擇「產品類別」
2. 可選擇「訂單狀態」
3. 可選擇「顯示前 N 名」（Top 5/10/20）
4. 可選擇「排序欄位」（金額/數量/日期）
5. 結果自動更新

---

**實作步驟：**

### **步驟 1：建立控制面板（新工作表「排行榜」）**

**A. 參數設定區：**

| 參數 | 儲存格 | 設定值 | 下拉選單 |
|------|--------|--------|----------|
| 產品類別 | B2 | 電腦周邊 | 8 個類別 |
| 訂單狀態 | B3 | 已完成 | 3 個狀態 |
| 顯示筆數 | B4 | 10 | 5/10/20 |
| 排序欄位 | B5 | 訂單總額 | 金額/數量/日期 |
| 排序方向 | B6 | 降序 | 升序/降序 |

**B. 建立下拉選單（資料驗證）：**

```excel
// B2: 產品類別下拉
資料驗證 → 清單來源：
電腦周邊,手機配件,家電用品,美妝保養,服飾配件,運動用品,書籍文具,食品飲料

// B3: 訂單狀態
已完成,處理中,已取消

// B4: 顯示筆數
5,10,20,50

// B5: 排序欄位
訂單總額,數量,訂單日期

// B6: 排序方向
升序,降序
```

---

### **步驟 2：建立動態排行榜公式（儲存格 A10）**

```excel
=LET(
    產品類別, 排行榜!B2,
    訂單狀態, 排行榜!B3,
    顯示筆數, 排行榜!B4,
    排序欄位, 排行榜!B5,
    排序方向, 排行榜!B6,

    // 確定排序欄位編號
    排序欄號, IF(排序欄位="訂單總額", 28, IF(排序欄位="數量", 17, 2)),

    // 確定排序方向
    排序順序, IF(排序方向="降序", -1, 1),

    // 篩選資料
    篩選結果, FILTER(
        訂單明細!A2:AN1001,
        (訂單明細!N2:N1001=產品類別) *
        (訂單明細!D2:D1001=訂單狀態),
        "查無符合條件的訂單"
    ),

    // 排序
    排序結果, SORT(篩選結果, 排序欄號, 排序順序),

    // 取前 N 筆
    TAKE(排序結果, 顯示筆數)
)
```

## 💡 重要觀念總結

### **SORT vs SORTBY 選擇指南**

**使用 SORT 當：**
- ✅ 排序欄位在結果中會顯示
- ✅ 單純的資料排序
- ✅ 不需要複雜的排序邏輯

**使用 SORTBY 當：**
- ✅ 排序欄位不想在結果中顯示
- ✅ 需要依照多個外部欄位排序
- ✅ 排序邏輯與顯示邏輯分離

### **函數組合技巧**

```
FILTER → SORT → TAKE
  ↓       ↓       ↓
 篩選   排序    取N筆

這是最常用的組合模式！
```

### **效能考量**

- SORT 比多次篩選+排序更快
- 先 FILTER 再 SORT（減少排序資料量）
- 使用 TAKE 比 FILTER 行號更有效率

## 🔧 常見錯誤與解決

### **錯誤 1：排序欄號錯誤**

```excel
// ❌ 錯誤
=SORT(A2:AN1001, 40, -1)  // AB 欄不是第 40 欄

// ✅ 正確
=SORT(A2:AN1001, 28, -1)  // AB 是第 28 欄
```

**如何算欄號？**
- A=1, B=2... Z=26
- AA=27, AB=28, AC=29...

### **錯誤 2：多欄位排序語法錯誤**

```excel
// ❌ 錯誤
=SORT(A2:AN1001, 14, 1, 28, -1)  // 語法錯誤

// ✅ 正確
=SORT(A2:AN1001, {14, 28}, {1, -1})  // 用 {} 包起來
```

### **錯誤 3：TAKE 取超過資料筆數**

```excel
// 如果只有 5 筆資料，但要取 10 筆
=TAKE(SORT(...), 10)  // 會報錯

// 解決方案：使用 IFERROR
=IFERROR(TAKE(SORT(...), 10), SORT(...))
```
