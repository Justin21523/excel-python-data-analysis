# Part 2: 日期函數實戰（2 小時）

## 📅 日期計算核心函數

### **練習 18：計算年齡（DATEDIF）**

**DATEDIF 語法：**
```excel
=DATEDIF(start_date, end_date, unit)
```

**Unit 參數：**
- `"Y"` - 整年數
- `"M"` - 整月數
- `"D"` - 整天數
- `"YM"` - 不含年的月數
- `"MD"` - 不含年月的天數
- `"YD"` - 不含年的天數

**範例：**
```excel
// 計算客戶年齡（假設 A2 是生日）
=DATEDIF(A2, TODAY(), "Y")  → 35（歲）

// 完整年齡表達
=DATEDIF(A2, TODAY(), "Y") & "歲" &
DATEDIF(A2, TODAY(), "YM") & "個月" &
DATEDIF(A2, TODAY(), "MD") & "天"
→ 35歲7個月15天
```

### **練習 20：月份邊界計算（EOMONTH）**

**EOMONTH 語法：**
```excel
=EOMONTH(start_date, months)
```
- `months = 0` → 當月月底
- `months = 1` → 下個月月底
- `months = -1` → 上個月月底

**範例：**
```excel
// 當月月底
=EOMONTH(TODAY(), 0)  → 2024-11-30

// 當月月初
=EOMONTH(TODAY(), -1) + 1  → 2024-11-01

// 下個月月底
=EOMONTH(TODAY(), 1)  → 2024-12-31

// 本季最後一天
=EOMONTH(DATE(YEAR(TODAY()), CEILING(MONTH(TODAY())/3,1)*3, 1), 0)
```

**應用場景：**
```excel
// 篩選本月訂單
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!B2:B1001 >= EOMONTH(TODAY(),-1)+1) *
    (訂單明細!B2:B1001 <= EOMONTH(TODAY(),0))
)
```

# Part 3: LET 函數高階應用（2 小時）

## 🎯 為什麼需要 LET？

**問題：重複計算**
```excel
// ❌ 不好的寫法（重複計算 3 次 FILTER）
=SORT(FILTER(...), 1) & " - " & COUNTA(FILTER(...)) & " 筆，總額 " & SUM(FILTER(...))
```

**解決：使用 LET**
```excel
// ✅ 好的寫法（只計算 1 次）
=LET(
    篩選結果, FILTER(...),
    SORT(篩選結果, 1) & " - " & COUNTA(篩選結果) & " 筆，總額 " & SUM(篩選結果)
)
```

**優點：**
- ✅ 效能提升（避免重複計算）
- ✅ 可讀性提升（命名變數）
- ✅ 易於維護和除錯

## 📊 LET 實戰練習

### **練習 24：簡化重複查找**

**題目：** 查找客戶資訊並格式化

**❌ 不使用 LET（重複查找 4 次）：**
```excel
="客戶：" & XLOOKUP(C2, 客戶主檔!A:A, 客戶主檔!B:B) &
"，電話：" & XLOOKUP(C2, 客戶主檔!A:A, 客戶主檔!D:D) &
"，地址：" & XLOOKUP(C2, 客戶主檔!A:A, 客戶主檔!E:E) &
"，會員：" & XLOOKUP(C2, 客戶主檔!A:A, 客戶主檔!F:F)
```

**✅ 使用 LET（只查找 1 次）：**
```excel
=LET(
    客戶ID, C2,
    客戶資訊, XLOOKUP(客戶ID, 客戶主檔!A:A, 客戶主檔!B:F),
    姓名, INDEX(客戶資訊, 1),
    電話, INDEX(客戶資訊, 3),
    地址, INDEX(客戶資訊, 4),
    會員等級, INDEX(客戶資訊, 5),
    "客戶：" & 姓名 & "，電話：" & 電話 & "，地址：" & 地址 & "，會員：" & 會員等級
)
```

### **練習 25：多步驟資料處理**

**題目：** 計算本月已完成訂單的平均金額（高於 5000 的）

**❌ 不使用 LET：**
```excel
=AVERAGE(FILTER(FILTER(訂單明細!AB2:AB1001,
(訂單明細!D2:D1001="已完成") * (訂單明細!B2:B1001>=EOMONTH(TODAY(),-1)+1) *
(訂單明細!B2:B1001<=EOMONTH(TODAY(),0))),
FILTER(訂單明細!AB2:AB1001, ...) > 5000))
```

**✅ 使用 LET：**
```excel
=LET(
    月初, EOMONTH(TODAY(), -1) + 1,
    月底, EOMONTH(TODAY(), 0),

    全部訂單, 訂單明細!A2:AN1001,
    訂單日期, 訂單明細!B2:B1001,
    訂單狀態, 訂單明細!D2:D1001,
    訂單金額, 訂單明細!AB2:AB1001,

    本月已完成, FILTER(訂單金額,
        (訂單狀態="已完成") *
        (訂單日期>=月初) *
        (訂單日期<=月底)
    ),

    高金額訂單, FILTER(本月已完成, 本月已完成>5000),

    AVERAGE(高金額訂單)
)
```

### **練習 26：動態查詢系統（完整範例）**

**題目：** 建立可配置的訂單查詢

**參數設定（在 B1:B5）：**
- B1: 產品類別（下拉選單）
- B2: 訂單狀態（下拉選單）
- B3: 最低金額
- B4: 最高金額
- B5: 排序欄位（金額/日期/數量）

**查詢公式（在 A10）：**
```excel
=LET(
    // 參數讀取
    類別, B1,
    狀態, B2,
    最低金額, B3,
    最高金額, B4,
    排序欄位, B5,

    // 資料來源
    全部資料, 訂單明細!A2:AN1001,

    // 篩選條件
    產品類別欄, 訂單明細!N2:N1001,
    訂單狀態欄, 訂單明細!D2:D1001,
    訂單金額欄, 訂單明細!AB2:AB1001,

    // 執行篩選
    篩選結果, FILTER(
        全部資料,
        (產品類別欄=類別) *
        (訂單狀態欄=狀態) *
        (訂單金額欄>=最低金額) *
        (訂單金額欄<=最高金額),
        "查無符合條件的訂單"
    ),

    // 確定排序欄位編號
    排序欄號, IF(排序欄位="金額", 28, IF(排序欄位="日期", 2, 17)),

    // 排序並返回
    SORT(篩選結果, 排序欄號, -1)
)
```

## 📚 建立自訂函數庫

### **練習 27：折扣計算函數**

**步驟 1：建立 LAMBDA**
```excel
=LAMBDA(原價, 折扣率, 原價 * (1 - 折扣率))
```

**步驟 2：命名函數（公式 → 名稱管理員）**
- 名稱：`折扣價`
- 範圍：整個活頁簿
- 參照到：`=LAMBDA(原價, 折扣率, 原價 * (1 - 折扣率))`

**步驟 3：使用函數**
```excel
=折扣價(1000, 0.15)  → 850
=折扣價(AB2, 0.1)    → 訂單金額打 9 折
```

**Python 對照：**
```python
def 折扣價(原價, 折扣率):
    return 原價 * (1 - 折扣率)
```

### **練習 28：會員等級判定函數**

**業務規則：**
- 總消費 < 10,000 → 普通會員
- 10,000 ≤ 總消費 < 50,000 → 銀卡會員
- 50,000 ≤ 總消費 < 100,000 → 金卡會員
- 總消費 ≥ 100,000 → 白金會員

**LAMBDA 定義：**
```excel
=LAMBDA(總消費,
    IF(總消費 < 10000, "普通會員",
    IF(總消費 < 50000, "銀卡會員",
    IF(總消費 < 100000, "金卡會員",
    "白金會員")))
)
```

**命名：** `會員等級`

**使用：**
```excel
=會員等級(5000)   → 普通會員
=會員等級(75000)  → 金卡會員
=會員等級(150000) → 白金會員
```

### **練習 29：文字清洗函數**

**功能：** 清除文字中的空格、特殊字元

**LAMBDA 定義：**
```excel
=LAMBDA(文字,
    TRIM(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(
        文字, CHAR(10), ""), CHAR(13), ""), "  ", " "))
)
```

**命名：** `清洗文字`

**說明：**
- `CHAR(10)` - 換行符號
- `CHAR(13)` - 回車符號
- `TRIM` - 移除前後空格
- `SUBSTITUTE` - 替換字元

**使用：**
```excel
=清洗文字(A2)  // 自動清理各種空白字元
```

## 🎯 完整專案：自動化 RFM 分析系統

**使用 LET + LAMBDA 建立可重複使用的 RFM 系統**

**步驟 1：建立 RFM 計算 LAMBDA**

```excel
// R - Recency (最近購買天數)
名稱：計算R值
=LAMBDA(客戶ID,
    DATEDIF(
        XLOOKUP(客戶ID, 訂單明細!C:C, 訂單明細!B:B, , 0, -1),
        TODAY(),
        "D"
    )
)

// F - Frequency (購買次數)
名稱：計算F值
=LAMBDA(客戶ID,
    COUNTIF(訂單明細!C:C, 客戶ID)
)

// M - Monetary (總消費金額)
名稱：計算M值
=LAMBDA(客戶ID,
    SUMIF(訂單明細!C:C, 客戶ID, 訂單明細!AB:AB)
)
```

**步驟 2：建立 RFM 評分 LAMBDA**

```excel
// R 評分（天數越少分數越高）
名稱：R評分
=LAMBDA(R值,
    IF(R值 <= 30, 5,
    IF(R值 <= 60, 4,
    IF(R值 <= 90, 3,
    IF(R值 <= 180, 2, 1))))
)

// F 評分（次數越多分數越高）
名稱：F評分
=LAMBDA(F值,
    IF(F值 >= 10, 5,
    IF(F值 >= 7, 4,
    IF(F值 >= 5, 3,
    IF(F值 >= 3, 2, 1))))
)

// M 評分（金額越多分數越高）
名稱：M評分
=LAMBDA(M值,
    IF(M值 >= 100000, 5,
    IF(M值 >= 50000, 4,
    IF(M值 >= 20000, 3,
    IF(M值 >= 10000, 2, 1))))
)
```

**步驟 3：建立完整 RFM 分析**

**在新工作表「RFM分析」中：**

```excel
// A2: 客戶ID列表
=UNIQUE(訂單明細!C2:C1001)

// B2: R值
=計算R值(A2)

// C2: F值
=計算F值(A2)

// D2: M值
=計算M值(A2)

// E2: R評分
=R評分(B2)

// F2: F評分
=F評分(C2)

// G2: M評分
=M評分(D2)

// H2: RFM 組合
=E2 & F2 & G2

// I2: 客戶分群
```
