## 📚 Part 1: LET() 函數（90 分鐘）

### 為什麼需要 LET？

**傳統公式的問題：**

```excel
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!D2:D1001="已完成") *
    (訂單明細!AB2:AB1001>AVERAGE(訂單明細!AB2:AB1001)) *
    (訂單明細!N2:N1001=INDEX(訂單明細!N2:N1001,
        MATCH(MAX(COUNTIF(訂單明細!N2:N1001, 訂單明細!N2:N1001)),
            COUNTIF(訂單明細!N2:N1001, 訂單明細!N2:N1001), 0)))
)
```

**問題：**
- ❌ 範圍重複多次（訂單明細!A2:AN1001 出現 3 次）
- ❌ 計算重複（AVERAGE 可能重複計算）
- ❌ 難以理解和維護
- ❌ 效能差（重複計算）

**使用 LET 改寫：**

```excel
=LET(
    全部訂單, 訂單明細!A2:AN1001,
    訂單狀態, 訂單明細!D2:D1001,
    訂單金額, 訂單明細!AB2:AB1001,
    產品類別, 訂單明細!N2:N1001,
    平均金額, AVERAGE(訂單金額),
    最熱門類別, INDEX(產品類別,
        MATCH(MAX(COUNTIF(產品類別, 產品類別)),
            COUNTIF(產品類別, 產品類別), 0)),
    FILTER(全部訂單,
        (訂單狀態="已完成") *
        (訂單金額>平均金額) *
        (產品類別=最熱門類別))
)
```

**優勢：**
- ✅ 程式碼清晰易讀
- ✅ 變數名稱有意義
- ✅ 避免重複計算
- ✅ 容易維護和修改

---

### 語法

```excel
=LET(name1, value1, [name2], [value2], ..., calculation)
```

**參數說明：**
- `name1`：變數名稱（自訂，不能與函數名重複）
- `value1`：變數值
- 可以定義多個變數
- 最後一個參數是「計算公式」（使用前面定義的變數）

---

### 範例 1：簡化重複計算

**情境：** 計算折扣後價格（原價、折扣率都會使用多次）

**傳統寫法：**
```excel
=A2 * (1 - B2) + A2 * (1 - B2) * 0.05
```

**LET 寫法：**
```excel
=LET(
    原價, A2,
    折扣率, B2,
    折扣價, 原價 * (1 - 折扣率),
    最終價, 折扣價 + 折扣價 * 0.05,
    最終價
)
```

**情境：** 計算客戶的會員等級（基於多個條件）

### 範例 3：簡化 FILTER + SORT 組合

**傳統寫法：**
```excel
=SORT(
    FILTER(訂單明細!A2:AN1001, 訂單明細!D2:D1001="已完成"),
    28, -1
)
```

**LET 寫法：**
```excel
=LET(
    全部訂單, 訂單明細!A2:AN1001,
    訂單狀態, 訂單明細!D2:D1001,
    已完成訂單, FILTER(全部訂單, 訂單狀態="已完成"),
    SORT(已完成訂單, 28, -1)
)
```

### 範例 4：動態查詢系統（完整範例）

**情境：** 建立可配置的訂單查詢

```excel
=LET(
    // 輸入參數
    查詢類別, B1,
    查詢狀態, B2,
    最低金額, B3,
    最高金額, B4,

    // 資料範圍
    全部訂單, 訂單明細!A2:AN1001,
    產品類別, 訂單明細!N2:N1001,
    訂單狀態, 訂單明細!D2:D1001,
    訂單金額, 訂單明細!AB2:AB1001,

    // 條件判斷
    類別條件, IF(查詢類別="全部", TRUE, 產品類別=查詢類別),
    狀態條件, IF(查詢狀態="全部", TRUE, 訂單狀態=查詢狀態),
    金額條件, (訂單金額>=最低金額) * (訂單金額<=最高金額),

    // 篩選結果
    篩選結果, FILTER(全部訂單, 類別條件 * 狀態條件 * 金額條件, "查無符合條件的訂單"),

    // 排序並返回
    SORT(篩選結果, 28, -1)
)
```

## 📖 Part 2: LAMBDA() 函數（90 分鐘）

### 什麼是 LAMBDA？

**LAMBDA 讓你建立「自訂函數」：**

```excel
=LAMBDA(參數1, 參數2, ..., 計算公式)
```

**就像 Python 的：**
```python
lambda x, y: x + y
```

---

### 範例 6：建立簡單的自訂函數

**情境：** 建立「計算折扣價」的函數

**定義函數（在名稱管理員中）：**
```excel
名稱：折扣價
公式：=LAMBDA(原價, 折扣率, 原價 * (1 - 折扣率))
```

**使用：**
```excel
=折扣價(1000, 0.2)  // 結果：800
=折扣價(A2, B2)     // 可以引用儲存格
```

---

### 範例 7：BMI 計算器

**定義函數：**
```excel
名稱：BMI計算
公式：=LAMBDA(身高cm, 體重kg,
    LET(
        身高m, 身高cm / 100,
        BMI值, 體重kg / (身高m ^ 2),
        ROUND(BMI值, 1)
    )
)
```

**使用：**
```excel
=BMI計算(170, 65)  // 結果：22.5
```

---

### 範例 8：文字清理函數

**定義函數：**
```excel
名稱：清理文字
公式：=LAMBDA(文字,
    LET(
        移除空格, TRIM(文字),
        轉大寫, UPPER(移除空格),
        轉大寫
    )
)
```

**使用：**
```excel
=清理文字("  hello world  ")  // 結果：HELLO WORLD
```

---

### 範例 9：日期格式化函數

## 🔥 Part 3: LAMBDA 與 MAP / REDUCE（60 分鐘）

### MAP() - 對陣列中每個元素執行函數

**語法：**
```excel
=MAP(array1, [array2], ..., lambda)
```

---

### 範例 10：計算陣列中每個數字的平方

```excel
=MAP(A1:A10, LAMBDA(x, x^2))
```

**解釋：**
- 對 A1:A10 中的每個值執行 `x^2`

---

### 範例 11：計算兩個陣列的和

```excel
=MAP(A1:A10, B1:B10, LAMBDA(x, y, x + y))
```

---

### 範例 12：格式化價格陣列

```excel
=MAP(A1:A10, LAMBDA(價格, TEXT(價格, "NT$ #,##0")))
```

**結果：**
```
NT$ 1,000
NT$ 2,500
NT$ 3,750
...
```

---

### REDUCE() - 累積運算

**語法：**
```excel
=REDUCE([initial_value], array, lambda)
```

---

### 範例 13：計算階乘

**情境：** 計算 5! = 5 × 4 × 3 × 2 × 1

```excel
=REDUCE(1, SEQUENCE(5), LAMBDA(累積值, 當前值, 累積值 * 當前值))
```

**執行過程：**
```
初始值：1
第 1 步：1 × 1 = 1
第 2 步：1 × 2 = 2
第 3 步：2 × 3 = 6
第 4 步：6 × 4 = 24
第 5 步：24 × 5 = 120
結果：120
```

---

### 範例 14：累計總和

```excel
=REDUCE(0, A1:A10, LAMBDA(累積, 當前, 累積 + 當前))
```

---

### SCAN() - 顯示每一步的累積結果

**語法：**
```excel
=SCAN([initial_value], array, lambda)
```

---

### 範例 15：累計銷售額（Running Total）

```excel
=SCAN(0, A1:A10, LAMBDA(累積, 當前, 累積 + 當前))
```

**結果（顯示每一步）：**
```
0
100
250
550
...
```

### 作業 2：建立動態 RFM 分析

**使用 LET 建立完整 RFM 公式：**

```excel
=LET(
    客戶ID, A2,

    // R - Recency（最近一次購買距今天數）
    最近購買日, MAXIFS(訂單明細!B:B, 訂單明細!E:E, 客戶ID, 訂單明細!D:D, "已完成"),
    R值, TODAY() - 最近購買日,

    // F - Frequency（購買次數）
    F值, COUNTIFS(訂單明細!E:E, 客戶ID, 訂單明細!D:D, "已完成"),

    // M - Monetary（總消費金額）
    M值, SUMIFS(訂單明細!AB:AB, 訂單明細!E:E, 客戶ID, 訂單明細!D:D, "已完成"),

    // 評分（1-5 分，使用五等分）
    R分數, IF(R值<=30, 5, IF(R值<=60, 4, IF(R值<=90, 3, IF(R值<=180, 2, 1)))),
    F分數, IF(F值>=10, 5, IF(F值>=7, 4, IF(F值>=4, 3, IF(F值>=2, 2, 1)))),
    M分數, IF(M值>=50000, 5, IF(M值>=30000, 4, IF(M值>=15000, 3, IF(M值>=5000, 2, 1)))),

    // RFM 組合
    RFM組合, R分數 & F分數 & M分數,

    // 客戶分群
    客戶群, IF((R分數>=4)*(F分數>=4)*(M分數>=4), "重要價值客戶",
              IF((R分數>=4)*(F分數>=3), "重要發展客戶",
                IF((R分數<=2)*(F分數>=3), "重要保持客戶",
                  IF((R分數>=4)*(M分數>=4), "重要挽留客戶",
                    IF(F分數>=3, "一般客戶", "潛在客戶"))))),

    // 輸出（可以選擇要顯示的欄位）
    HSTACK(R值, F值, M值, R分數, F分數, M分數, RFM組合, 客戶群)
)
```

### 🎓 Excel → Python 對照

| Excel 功能 | Python 對應 |
|-----------|-----------|
| `=LET(x, 10, x*2)` | `x = 10; x * 2` |
| `=LAMBDA(x, x*2)` | `lambda x: x*2` |
| `=MAP(A:A, LAMBDA(x, x*2))` | `df['A'].apply(lambda x: x*2)` |
| `=REDUCE(0, A:A, LAMBDA(a,b, a+b))` | `df['A'].sum()` 或 `reduce(lambda a,b: a+b, list)` |

### 常見錯誤

**錯誤 1：變數名稱與函數名稱衝突**
```excel
❌ =LET(SUM, 100, SUM*2)  // SUM 是函數名
✅ =LET(總和, 100, 總和*2)
```

**錯誤 2：忘記最後的計算公式**
```excel
❌ =LET(x, 10, y, 20)  // 缺少計算
✅ =LET(x, 10, y, 20, x+y)
```

**錯誤 3：LAMBDA 參數數量不符**
```excel
=LAMBDA(x, y, x+y)  // 定義 2 個參數
❌ =函數名(10)  // 只傳 1 個參數
✅ =函數名(10, 20)  // 傳 2 個參數
```
