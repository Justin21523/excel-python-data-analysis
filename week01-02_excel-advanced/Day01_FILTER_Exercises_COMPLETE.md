## 🎯 練習題系統

### **基礎練習（30 分鐘）**

#### **練習 1：單一條件篩選**

**題目：** 篩選出所有「已完成」的訂單

**提示：**
- 使用欄位：D (訂單狀態)
- 條件：等於「已完成」

**Excel 公式：**
```excel
=FILTER(訂單明細!A2:AN1001, 訂單明細!D2:D1001="已完成")
```

**Python 對照：**
```python
df[df['訂單狀態'] == '已完成']
```

**預期結果：**
- 應該看到所有狀態為「已完成」的訂單列
- 約 700-800 筆資料（訂單完成率約 70-80%）
- 檢查：D 欄所有值都應該是「已完成」

**除錯技巧：**
- 如果出現 #CALC! 錯誤：檢查範圍是否一致（A2:AN1001 和 D2:D1001 行數要相同）
- 如果沒有結果：確認字串完全匹配（注意中英文、空格）

#### **練習 2：數值條件篩選**

**題目：** 篩選出訂單總額大於 10,000 元的訂單

**提示：**
- 使用欄位：AB (訂單總額)
- 條件：> 10000

**Excel 公式：**
```excel
=FILTER(訂單明細!A2:AN1001, 訂單明細!AB2:AB1001>10000)
```

**Python 對照：**
```python
df[df['訂單總額'] > 10000]
```

**預期結果：**
- 大額訂單（通常是 3C 產品、家電）
- 約 200-300 筆資料
- 檢查：AB 欄所有值都應該 > 10,000

**進階挑戰：**
同時顯示訂單總額和產品類別：
```excel
=FILTER(訂單明細!A2:AN1001, 訂單明細!AB2:AB1001>10000)
```
觀察哪些類別容易產生大額訂單。

#### **練習 3：文字包含篩選**

**題目：** 篩選出產品名稱包含「Apple」的訂單

**提示：**
- 使用欄位：O (產品名稱)
- 函數組合：ISNUMBER + SEARCH

**Excel 公式：**
```excel
=FILTER(訂單明細!A2:AN1001, ISNUMBER(SEARCH("Apple", 訂單明細!O2:O1001)))
```

**Python 對照：**
```python
df[df['產品名稱'].str.contains('Apple', na=False)]
```

**公式解析：**
1. `SEARCH("Apple", O2:O1001)` - 在產品名稱中搜尋「Apple」
2. 找到返回位置（數字），找不到返回 #VALUE!
3. `ISNUMBER()` - 將數字轉為 TRUE，錯誤值轉為 FALSE
4. `FILTER()` - 只保留 TRUE 的列

**預期結果：**
- Apple 相關產品：iPhone, AirPods, MacBook 等
- 約 50-100 筆資料
- 檢查：O 欄都應該包含「Apple」字樣

### **進階練習（60 分鐘）**

#### **練習 4：AND 條件（多條件同時滿足）**

**題目：** 篩選出「已完成」且「訂單總額 > 5000」的訂單

**提示：**
- 兩個條件都要滿足
- 使用 `*` 運算子（AND 邏輯）

**Excel 公式：**
```excel
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!D2:D1001="已完成") * (訂單明細!AB2:AB1001>5000)
)
```

**Python 對照：**
```python
df[(df['訂單狀態'] == '已完成') & (df['訂單總額'] > 5000)]
```

**公式解析：**
- `()` 每個條件用括號包起來
- `*` 乘法運算子實現 AND（兩個都是 TRUE 才會是 TRUE）
- TRUE * TRUE = TRUE (1 × 1 = 1)
- TRUE * FALSE = FALSE (1 × 0 = 0)

**預期結果：**
- 已完成的大額訂單
- 約 300-400 筆資料
- 檢查：D 欄都是「已完成」，AB 欄都 > 5000

---

#### **練習 5：OR 條件（滿足任一條件即可）**

**題目：** 篩選出產品類別為「電腦周邊」或「手機配件」的訂單

**提示：**
- 任一條件滿足即可
- 使用 `+` 運算子（OR 邏輯）

**Excel 公式：**
```excel
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!N2:N1001="電腦周邊") + (訂單明細!N2:N1001="手機配件")
)
```

**Python 對照：**
```python
df[df['產品類別'].isin(['電腦周邊', '手機配件'])]
# 或
df[(df['產品類別'] == '電腦周邊') | (df['產品類別'] == '手機配件')]
```

**公式解析：**
- `+` 加法運算子實現 OR（任一為 TRUE 即為 TRUE）
- TRUE + FALSE = TRUE (1 + 0 = 1)
- FALSE + FALSE = FALSE (0 + 0 = 0)

**預期結果：**
- 3C 類產品訂單
- 約 200-300 筆資料
- 檢查：N 欄應該只有「電腦周邊」或「手機配件」

#### **練習 6：日期範圍篩選**

**題目：** 篩選出 2024 年 11 月的訂單

**提示：**
- 使用欄位：B (訂單日期)
- 使用 DATE 函數建立日期範圍

**Excel 公式：**
```excel
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!B2:B1001>=DATE(2024,11,1)) *
    (訂單明細!B2:B1001<=DATE(2024,11,30))
)
```

**Python 對照：**
```python
df[(df['訂單日期'] >= '2024-11-01') & (df['訂單日期'] <= '2024-11-30')]
```

**公式解析：**
- `DATE(2024,11,1)` - 2024 年 11 月 1 日
- `DATE(2024,11,30)` - 2024 年 11 月 30 日
- 兩個條件用 `*` 連接（AND）

**預期結果：**
- 11 月份的所有訂單
- 約 300-400 筆資料（假設資料跨 3 個月）
- 檢查：B 欄日期都在 2024/11/01 到 2024/11/30 之間

**進階挑戰：**
只看 11 月前兩週的訂單：
```excel
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!B2:B1001>=DATE(2024,11,1)) *
    (訂單明細!B2:B1001<=DATE(2024,11,14))
)
```

#### **練習 7：複雜多條件組合**

**題目：** 篩選出「北部地區」且「金卡或白金會員」且「已完成訂單」且「訂單總額 > 3000」

**提示：**
- 4 個條件
- 混合使用 AND (*) 和 OR (+)

**Excel 公式：**
```excel
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!F2:F1001="北部") *
    ((訂單明細!Y2:Y1001="金卡") + (訂單明細!Y2:Y1001="白金")) *
    (訂單明細!D2:D1001="已完成") *
    (訂單明細!AB2:AB1001>3000)
)
```

**Python 對照：**
```python
df[
    (df['配送地區'] == '北部') &
    (df['會員等級'].isin(['金卡', '白金'])) &
    (df['訂單狀態'] == '已完成') &
    (df['訂單總額'] > 3000)
]
```

**公式解析：**
1. 北部地區（必須）
2. 金卡或白金會員（OR 條件用括號包起來）
3. 已完成（必須）
4. 金額 > 3000（必須）
5. 用 `*` 連接所有主要條件

**預期結果：**
- 北部高價值會員的已完成訂單
- 約 50-100 筆資料
- 檢查所有條件都滿足

**除錯技巧：**
如果公式太複雜，可以分步驟測試：
```excel
// 步驟1：先測試單一條件
=FILTER(訂單明細!A2:AN1001, 訂單明細!F2:F1001="北部")

// 步驟2：逐步加入條件
=FILTER(訂單明細!A2:AN1001,
    (訂單明細!F2:F1001="北部") * (訂單明細!D2:D1001="已完成"))

// 步驟3：完整公式
```

#### **練習 9：動態篩選系統（LET 函數）**

**題目：** 建立可重複使用的篩選查詢，篩選「特定付款方式」且「金額範圍」的訂單

**提示：**
- 使用 LET 函數定義變數
- 方便修改條件

**Excel 公式：**
```excel
=LET(
    付款方式, "信用卡",
    最低金額, 5000,
    最高金額, 20000,
    資料範圍, 訂單明細!A2:AN1001,
    FILTER(
        資料範圍,
        (訂單明細!H2:H1001=付款方式) *
        (訂單明細!AB2:AB1001>=最低金額) *
        (訂單明細!AB2:AB1001<=最高金額)
    )
)
```

**Python 對照：**
```python
# 定義變數
payment_method = "信用卡"
min_amount = 5000
max_amount = 20000

# 篩選
df[
    (df['付款方式'] == payment_method) &
    (df['訂單總額'] >= min_amount) &
    (df['訂單總額'] <= max_amount)
]
```

**優點：**
- 修改條件時只需改變變數值
- 公式更易讀
- 可重複使用

#### **練習 10：FILTER + SORT 組合**

**題目：** 篩選出「電腦周邊」類別的訂單，並按訂單總額由高到低排序，只顯示前 10 名

**Excel 公式：**
```excel
=TAKE(
    SORT(
        FILTER(
            訂單明細!A2:AN1001,
            訂單明細!N2:N1001="電腦周邊"
        ),
        28, -1
    ),
    10
)
```

**Python 對照：**
```python
df[df['產品類別'] == '電腦周邊'].sort_values('訂單總額', ascending=False).head(10)
```

**公式解析（由內而外）：**
1. `FILTER()` - 先篩選出電腦周邊類別
2. `SORT(... , 28, -1)` - 按第 28 欄（AB 欄 = 訂單總額）降序排序
   - 28 是因為從 A 到 AB 共 28 個欄位
   - -1 表示降序（由大到小）
3. `TAKE(... , 10)` - 只取前 10 筆

**預期結果：**
- 電腦周邊類別中金額最高的 10 筆訂單
- 應該都是高單價產品（如 MacBook、高階顯卡等）

| 參數名稱 | 儲存格 | 設定值 |
|---------|--------|--------|
| 訂單狀態 | B2 | 已完成 |

```excel

    結束日期, 查詢設定!B4,

            (訂單明細!B2:B1001<=結束日期) *
            (訂單明細!AB2:AB1001>=最低金額) *
```

## 💡 除錯常見問題

### **問題 1：#CALC! 錯誤**
**原因：** 範圍行數不一致
```excel
// ❌ 錯誤
=FILTER(A2:AN1001, D2:D1000)  // 1000 vs 999 行

// ✅ 正確
=FILTER(A2:AN1001, D2:D1001)  // 都是 1000 行
```

### **問題 2：#SPILL! 錯誤**
**原因：** 結果溢出範圍被佔用
**解決：** 清空公式下方和右方的儲存格

### **問題 3：沒有結果顯示**
**檢查：**
1. 條件是否正確（檢查字串、日期格式）
2. 是否所有資料都不符合條件
3. 使用 if_empty 參數確認

### **問題 4：公式太長難以閱讀**
**解決：** 使用 LET 函數拆分
```excel
=LET(
    資料, 訂單明細!A2:AN1001,
    狀態條件, 訂單明細!D2:D1001="已完成",
    金額條件, 訂單明細!AB2:AB1001>5000,
    FILTER(資料, 狀態條件 * 金額條件)
)
```
