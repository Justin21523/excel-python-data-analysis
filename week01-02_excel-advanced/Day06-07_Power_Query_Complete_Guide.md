## 📚 Day 6 Part 1: Power Query 基礎（4 小時）

### 什麼是 Power Query？

**Power Query 是什麼：**
- Microsoft 的資料轉換與整合工具
- 內建於 Excel 2016+ 和 Power BI
- 用於 ETL（Extract-Transform-Load）

**為什麼要用 Power Query：**
- ✅ 可重複執行（按下「重新整理」即可）
- ✅ 不修改來源資料（非破壞性）
- ✅ 自動記錄每個步驟
- ✅ 批次處理多個檔案
- ✅ 比 Excel 公式更強大、更快速

**與 Excel 公式的差異：**

| 特性 | Excel 公式 | Power Query |
|------|-----------|-------------|
| 資料來源 | 僅限工作表內 | 多種來源（檔案、資料庫、網頁） |
| 修改原資料 | 是 | 否（非破壞性） |
| 批次處理 | 困難 | 簡單 |
| 效能 | 大資料量慢 | 針對大資料優化 |
| 可重複執行 | 手動 | 一鍵重新整理 |

## 📖 Day 6 Part 2: 資料轉換進階（4 小時）

### Unpivot（取消樞紐）- 寬表轉長表

**什麼是 Unpivot：**
- 將「寬格式」轉成「長格式」
- 將多個欄位合併成兩個欄位（屬性 + 值）

**使用情境：**
- 原始資料：每個月一欄
- 需要：月份和銷售額兩欄（方便分析）

**範例：寬表**
```
| 產品   | 1月 | 2月 | 3月 |
|--------|-----|-----|-----|
| 產品A  | 100 | 150 | 200 |
| 產品B  | 80  | 90  | 110 |
```

**Unpivot 後：長表**
```
| 產品   | 月份 | 銷售額 |
|--------|------|--------|
| 產品A  | 1月  | 100    |
| 產品A  | 2月  | 150    |
| 產品A  | 3月  | 200    |
| 產品B  | 1月  | 80     |
| 產品B  | 2月  | 90     |
| 產品B  | 3月  | 110    |
```

**操作步驟：**

1. 選取「產品」欄位（識別碼欄位，不要 Unpivot）
2. 右鍵 > **取消樞紐其他欄位**
3. 結果：
   - 「屬性」欄位：月份（1月、2月、3月）
   - 「值」欄位：銷售額
4. 重新命名欄位：
   - 「屬性」→「月份」
   - 「值」→「銷售額」

**Python 等效：**
```python
df.melt(id_vars=['產品'], var_name='月份', value_name='銷售額')
```

### Pivot（樞紐）- 長表轉寬表

**什麼是 Pivot：**
- 將「長格式」轉成「寬格式」
- 將某欄位的值變成欄位標題

**範例：長表**
```
| 日期       | 產品   | 數量 |
|-----------|--------|------|
| 2024-11-01| 產品A  | 10   |
| 2024-11-01| 產品B  | 8    |
| 2024-11-02| 產品A  | 12   |
| 2024-11-02| 產品B  | 9    |
```

**Pivot 後：寬表**
```
| 日期       | 產品A | 產品B |
|-----------|-------|-------|
| 2024-11-01| 10    | 8     |
| 2024-11-02| 12    | 9     |
```

**操作步驟：**

1. 選取「產品」欄位（要變成欄位標題的欄位）
2. 轉換 > **樞紐資料行**
3. 值資料行：選擇「數量」
4. 進階選項：
   - 彙總函數：總和（預設）
   - 也可選擇：計數、平均、最大、最小
5. 確定

**Python 等效：**
```python
df.pivot(index='日期', columns='產品', values='數量')
# 或
df.pivot_table(index='日期', columns='產品', values='數量', aggfunc='sum')
```

### Group By（分組彙總）

**什麼是 Group By：**
- 根據某些欄位分組
- 對每組進行彙總計算（sum、count、avg、max、min）

**範例：計算每個產品類別的總銷售額和訂單數**

**操作步驟：**

1. 常用 > **分組依據**
2. 分組依據：選擇「產品類別」
3. 點擊「新增彙總」：
   - 新欄位名稱：`總銷售額`
   - 作業：總和
   - 欄位：訂單總額
4. 再點擊「新增彙總」：
   - 新欄位名稱：`訂單數`
   - 作業：計算資料列
5. 確定

**結果：**
```
| 產品類別   | 總銷售額 | 訂單數 |
|-----------|---------|--------|
| 電腦周邊   | 850000  | 150    |
| 手機配件   | 620000  | 180    |
| 家電      | 1200000 | 95     |
```

**Python 等效：**
```python
df.groupby('產品類別').agg({
    '訂單總額': 'sum',
    '訂單編號': 'count'
}).rename(columns={'訂單總額': '總銷售額', '訂單編號': '訂單數'})
```

### Merge（合併查詢）- 類似 SQL JOIN

**什麼是 Merge：**
- 將兩個資料表根據「共同欄位」合併
- 類似 Excel 的 VLOOKUP，但更強大

**Join 類型：**

1. **Left Outer**：保留左表所有資料，右表沒有匹配的顯示 null
2. **Right Outer**：保留右表所有資料
3. **Full Outer**：保留兩表所有資料
4. **Inner**：只保留兩表都有匹配的資料
5. **Left Anti**：只保留左表「沒有」匹配的資料（找出差異）
6. **Right Anti**：只保留右表「沒有」匹配的資料

**範例：將訂單與客戶資料合併**

**訂單表：**
```
| 訂單編號 | 客戶ID | 金額  |
|---------|--------|------|
| ORD001  | CUS001 | 5000 |
| ORD002  | CUS002 | 3000 |
```

**客戶表：**
```
| 客戶ID | 客戶姓名 | 會員等級 |
|--------|---------|---------|
| CUS001 | 王小明   | 鑽石     |
| CUS002 | 李小華   | 黃金     |
```

**操作步驟：**

1. 在「訂單」查詢中，常用 > **合併查詢**
2. 選擇要合併的另一個資料表：「客戶」
3. 選擇匹配欄位：
   - 訂單表：客戶ID
   - 客戶表：客戶ID
4. 聯結類型：Left Outer（預設）
5. 確定
6. **展開合併的欄位**：
   - 點擊新欄位標題右邊的「雙箭頭」按鈕
   - 勾選要顯示的欄位：客戶姓名、會員等級
   - 取消勾選「使用原始欄位名稱作為前置詞」
   - 確定

**結果：**
```
| 訂單編號 | 客戶ID | 金額  | 客戶姓名 | 會員等級 |
|---------|--------|------|---------|---------|
| ORD001  | CUS001 | 5000 | 王小明   | 鑽石     |
| ORD002  | CUS002 | 3000 | 李小華   | 黃金     |
```

**Python 等效：**
```python
pd.merge(訂單表, 客戶表, on='客戶ID', how='left')
```

### Append（附加查詢）- 垂直合併

**什麼是 Append：**
- 將多個結構相同的資料表「垂直堆疊」
- 類似 SQL 的 UNION ALL

**使用情境：**
- 合併每月銷售資料（1月 + 2月 + 3月）
- 合併多個分店的訂單

**操作步驟：**

1. 常用 > **附加查詢**
2. 選擇：「兩個資料表」或「三個或多個資料表」
3. 如果選「三個或多個」：
   - 可用的資料表：選擇要合併的所有資料表
   - 點擊「新增」移到右側
4. 確定

**結果：** 所有資料表的資料堆疊在一起

**注意事項：**
- 欄位名稱必須一致
- 如果欄位不一致，會自動加上 null

**Python 等效：**
```python
pd.concat([df1, df2, df3], ignore_index=True)
```

### 專案 1：多檔案銷售資料整合

**情境：**
- 有 3 個分店，各自提供 Excel 檔案
- 檔案名稱：`branch_台北.xlsx`、`branch_台中.xlsx`、`branch_高雄.xlsx`
- 每個檔案格式一致

**目標：**
- 合併成一張完整的銷售表
- 加上「分店」欄位

**步驟：**

1. **從資料夾載入**
   - 資料 > 從資料夾
   - 選擇包含 3 個檔案的資料夾

2. **篩選 Excel 檔案**
   - 篩選「Extension」欄位 = `.xlsx`

3. **提取分店名稱（從檔名）**
   - 新增自訂欄位：
     ```m
     = Text.BetweenDelimiters([Name], "_", ".")
     ```
   - 結果：台北、台中、高雄

4. **展開檔案內容**
   - 點擊「Content」欄位的雙箭頭
   - 選擇工作表「銷售明細」

5. **展開資料**
   - 點擊新欄位的雙箭頭
   - 選擇所有欄位

6. **清理不需要的欄位**
   - 移除：Content、Folder Path、Extension 等

7. **重新命名**
   - 將提取的欄位改名為「分店」

8. **關閉並載入**

**結果：** 一張包含所有分店資料的完整表格，並有「分店」欄位標識來源

### 專案 2：髒資料清理流程

**情境：**
- 客戶提供的 Excel 資料很髒：
  - 有空白列
  - 欄位名稱不一致
  - 日期格式混亂
  - 有重複資料

**目標：** 建立自動化清理流程

**步驟：**

1. **載入資料**
   - 從檔案 > 從活頁簿

2. **移除空白列**
   - 常用 > 移除列 > 移除空白列

3. **統一欄位名稱**
   - 轉換 > 使用第一列作為標題（如果需要）
   - 手動重新命名混亂的欄位

4. **清理文字欄位**
   - 選取所有文字欄位
   - 轉換 > 格式 > 修剪（移除前後空格）
   - 轉換 > 格式 > 清除（移除特殊字元）

5. **修正日期格式**
   - 選取日期欄位
   - 轉換 > 資料類型 > 日期
   - 如果格式不正確，使用自訂欄位：
     ```m
     = Date.FromText([原始日期], "zh-TW")
     ```

6. **移除重複列**
   - 常用 > 移除列 > 移除重複項
   - 選擇用來判斷重複的欄位（例如：訂單編號）

7. **填補缺失值**
   - 選取欄位
   - 轉換 > 填滿 > 向下（複製上一列的值）
   - 或：轉換 > 取代值 > 將 null 取代為 0

8. **驗證資料**
   - 檢查每個欄位的資料類型
   - 檢查數值範圍（篩選看是否有異常值）

**結果：** 乾淨、標準化的資料表

### 專案 3：訂單與產品、客戶整合

**情境：**
- 有 3 張表：訂單、產品、客戶
- 需要整合成完整的分析表

**訂單表：** 訂單編號、客戶ID、產品ID、數量、金額
**產品表：** 產品ID、產品名稱、品牌、類別、單價
**客戶表：** 客戶ID、客戶姓名、會員等級、註冊日期

**目標：** 建立包含所有資訊的完整表

**步驟：**

1. **載入 3 張表**
   - 分別載入訂單、產品、客戶

2. **Merge 1：訂單 + 產品**
   - 在「訂單」查詢中
   - 合併查詢 > 選擇「產品」
   - 匹配欄位：產品ID
   - Left Outer Join
   - 展開：產品名稱、品牌、類別、單價

3. **Merge 2：結果 + 客戶**
   - 再次合併查詢 > 選擇「客戶」
   - 匹配欄位：客戶ID
   - Left Outer Join
   - 展開：客戶姓名、會員等級、註冊日期

4. **新增計算欄位**
   - 毛利 = 金額 - (單價 × 數量 × 0.7)  // 假設成本率 70%
   - 毛利率 = 毛利 / 金額

5. **重新排列欄位**
   - 拖曳欄位調整順序
   - 邏輯順序：訂單資訊 > 客戶資訊 > 產品資訊 > 金額資訊

6. **關閉並載入**

**結果：** 一張包含訂單、產品、客戶所有資訊的完整寬表，可直接用於分析

- 新增計算欄位（M 語言）

**進階轉換：**
- **Unpivot**：寬表 → 長表（分析友善格式）
- **Pivot**：長表 → 寬表（報表友善格式）
- **Group By**：分組彙總（sum/count/avg/max/min）
- **Merge**：水平合併（LEFT/RIGHT/INNER/OUTER/ANTI JOIN）
- **Append**：垂直合併（堆疊資料）

**實務應用：**
- 批次處理多個檔案
- 髒資料清理流程
- 多表整合
- 自動更新報表

### 🎓 Power Query → Python pandas 對照

| Power Query 操作 | Python pandas 對應 |
|-----------------|-------------------|
| Unpivot | `df.melt()` |
| Pivot | `df.pivot()` 或 `df.pivot_table()` |
| Group By | `df.groupby().agg()` |

| Merge (Inner) | `pd.merge(how='inner')` |
| Append | `pd.concat()` |
| 移除重複 | `df.drop_duplicates()` |

| 新增欄位 | `df['new_col'] = ...` |
| 修剪空格 | `df['col'].str.strip()` |

### 常見錯誤

**錯誤 1：資料類型不正確**
- 症狀：計算錯誤、無法彙總
- 解決：變更資料類型（ABC → 123 → 日曆）

**錯誤 2：Merge 後忘記展開**
- 症狀：出現「Table」字樣而非實際資料
- 解決：點擊欄位標題右邊的雙箭頭

**錯誤 3：Unpivot 選錯欄位**
- 症狀：識別碼欄位也被 Unpivot 了
- 解決：應該先選「識別碼欄位」，然後「取消樞紐其他欄位」

**錯誤 4：Append 欄位名稱不一致**
- 症狀：出現很多 null 值
- 解決：統一所有資料表的欄位名稱

### 效能優化技巧

1. **先篩選再轉換**
   - 在「套用的步驟」中，將篩選步驟移到前面
   - 減少處理的資料量

2. **移除不需要的欄位**
   - 越早移除越好
   - 減少記憶體使用

3. **使用正確的資料類型**
   - 文字 vs 數字 vs 日期
   - 正確的類型效能更好

4. **避免過多的自訂欄位**
   - 盡量使用內建函數
   - M 語言效能優化過

### 終極專案：建立完整 ETL 系統

**情境：**
- 3 個分店每天產生 CSV 訂單檔
- 有產品主檔（Excel）和客戶主檔（Excel）
- 需要：每天自動整合並產生分析報表

**需求：**
1. 自動載入所有訂單檔案
2. 清理髒資料
3. 整合產品和客戶資訊
4. 計算關鍵指標
5. 輸出到 Excel 工作表
6. 一鍵重新整理

**步驟提示：**

1. **查詢 1：訂單資料**
   - 從資料夾載入所有 CSV
   - 提取分店名稱（從檔名）
   - 清理資料（修剪、移除空白列、統一格式）

2. **查詢 2：產品主檔**
   - 從 Excel 載入
   - 確認資料類型

3. **查詢 3：客戶主檔**
   - 從 Excel 載入
   - 計算「註冊天數」

4. **查詢 4：完整訂單表（整合）**
   - Merge 查詢 1 + 查詢 2（產品資訊）
   - Merge 結果 + 查詢 3（客戶資訊）
   - 新增計算欄位：毛利、毛利率

5. **查詢 5：分店彙總**
   - 從查詢 4 載入
   - Group By 分店：總銷售額、訂單數、平均客單價

6. **查詢 6：產品類別彙總**
   - 從查詢 4 載入
   - Group By 產品類別：總銷售額、銷售數量

7. **關閉並載入到不同工作表**
   - 查詢 4 → 「訂單明細」工作表
   - 查詢 5 → 「分店彙總」工作表
   - 查詢 6 → 「產品彙總」工作表

**測試：**
- 新增一個 CSV 檔案
- 資料 > 全部重新整理
- 觀察所有工作表是否更新
