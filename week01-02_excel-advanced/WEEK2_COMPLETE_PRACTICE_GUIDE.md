**🎯 目標：** 建立一個顯示各產品類別銷售總額的樞紐表

**步驟：**
1. 選取資料範圍 A1:AN1001

4. 設定欄位：
   - **列：** 產品類別
   - **值：** 訂單總額（加總）

**✅ 完整操作步驟：**

#### 練習 A4: 建立「平均客單價」計算欄位

**🎯 目標：** 使用計算欄位計算：平均客單價 = 銷售額 / 訂單數

**步驟：**
1. 建立基礎樞紐表（產品類別 × 銷售額 + 訂單數）
2. 樞紐分析表分析 → 欄位、項目與集 → 計算欄位
3. 名稱：平均客單價
4. 公式：`=訂單總額/訂單總額`（注意：第二個是計數）

**✅ 完整操作步驟：**
```
1. 建立樞紐表：
   - 列：產品類別
   - 值：訂單總額（加總）、訂單總額（計數）

2. 點擊樞紐表任一儲存格
3. 樞紐分析表分析 → 欄位、項目與集 → 計算欄位
4. 在對話框中：
   - 名稱：平均客單價
   - 公式：=訂單總額
   - 點擊「插入欄位」→ 選擇「訂單總額」
   - 在公式中繼續輸入：/訂單總額
   - （Excel 會自動計算加總/計數 = 平均）
```

**⚠️ 重要提醒：**
- 計算欄位中的「訂單總額」會自動使用**加總後的值**
- 如果同時有多個聚合函數，Excel 會根據上下文選擇

**🔍 驗證結果：**
- 應該出現新的「加總 - 平均客單價」欄位
- 數值 = 該類別的總銷售額 / 訂單數
