## 📚 Part 1: SORT() 基礎（45 分鐘）

### 語法

```excel
=SORT(array, [sort_index], [sort_order], [by_col])
```

**參數說明：**
- `array`：要排序的資料範圍
- `[sort_index]`：按第幾欄排序（預設 1）
- `[sort_order]`：1=升序（預設），-1=降序
- `[by_col]`：TRUE=按欄排序，FALSE=按列排序（預設）

---

### 範例 1：單欄排序（升序）

**情境：** 按訂單總額從低到高排序

```excel
=SORT(訂單明細!A2:AN1001, 28, 1)
```

**解釋：**
- `訂單明細!A2:AN1001`：全部資料
- `28`：第 28 欄（訂單總額，對應 AB 欄）
- `1`：升序（小到大）

**簡化寫法（預設升序）：**
```excel
=SORT(訂單明細!A2:AN1001, 28)
```

---

### 範例 2：單欄排序（降序）

**情境：** 按訂單總額從高到低排序（找出大額訂單）

```excel
=SORT(訂單明細!A2:AN1001, 28, -1)
```

**解釋：**
- `-1`：降序（大到小）

**用途：** 快速找出最高消費的訂單

---

### 範例 3：多欄排序

**情境：** 先按產品類別排序，同類別內再按金額降序

```excel
=SORT(訂單明細!A2:AN1001, {14, 28}, {1, -1})
```

**解釋：**
- `{14, 28}`：先按第 14 欄（產品類別），再按第 28 欄（訂單總額）
- `{1, -1}`：類別升序（A-Z），金額降序（大到小）

**陣列寫法：**
- 用大括號 `{}` 包起來
- 用逗號 `,` 分隔多個值

---

### 範例 4：按日期排序

**情境：** 按訂單時間從新到舊

```excel
=SORT(訂單明細!A2:AN1001, 2, -1)
```

**解釋：**
- `2`：第 2 欄（訂單時間）
- `-1`：降序（最新的在最上面）

## 📖 Part 2: SORTBY() 進階（45 分鐘）

### 為什麼需要 SORTBY？

**SORT 的限制：**
- 只能按「本身的某一欄」排序
- 無法按「其他範圍」排序

**SORTBY 的優勢：**
- 可以按任意其他範圍排序
- 可以組合多個排序依據

### 語法

```excel
=SORTBY(array, by_array1, [sort_order1], [by_array2], [sort_order2], ...)
```

**參數說明：**
- `array`：要排序的資料範圍
- `by_array1`：排序依據（可以是外部範圍）
- `[sort_order1]`：1=升序，-1=降序
- 可以有多個 by_array 和 sort_order

---

### 範例 5：按其他欄位排序

**情境：** 只顯示「訂單編號、客戶姓名、產品名稱」，但按「訂單總額」降序排列

```excel
=SORTBY(
    CHOOSECOLS(訂單明細!A2:AN1001, 1, 6, 15),
    訂單明細!AB2:AB1001,
    -1
)
```

**解釋：**
- `CHOOSECOLS(..., 1, 6, 15)`：只選 3 欄
- `訂單明細!AB2:AB1001`：按訂單總額排序（這一欄沒有顯示）
- `-1`：降序

---

### 範例 6：多重排序依據

**情境：** 先按會員等級，再按消費金額

```excel
=SORTBY(
    訂單明細!A2:AN1001,
    訂單明細!K2:K1001, 1,
    訂單明細!AB2:AB1001, -1
)
```

**解釋：**
- 第一排序：會員等級（K 欄）升序
- 第二排序：訂單總額（AB 欄）降序

---

### 範例 7：按計算結果排序

**情境：** 按「商品單價 × 數量」排序（不顯示這個計算欄位）

```excel
=SORTBY(
    訂單明細!A2:AN1001,
    訂單明細!R2:R1001 * 訂單明細!S2:S1001,
    -1
)
```

**解釋：**
- `訂單明細!R2:R1001 * 訂單明細!S2:S1001`：單價 × 數量
- 結果不顯示在輸出中，只用來排序

## 🔥 Part 3: FILTER + SORT 組合技（60 分鐘）

### 組合模式 1：先篩選，再排序

**情境：** 找出「已完成」的訂單，按金額降序排列

```excel
=SORT(
    FILTER(訂單明細!A2:AN1001, 訂單明細!D2:D1001="已完成"),
    28,
    -1
)
```

**執行順序：**
1. FILTER 先篩選出「已完成」的訂單
2. SORT 再按第 28 欄（訂單總額）降序排列

---

### 組合模式 2：Top N 排名

**情境：** 找出「訂單總額 Top 10」

**Step 1: 先排序**
```excel
=SORT(訂單明細!A2:AN1001, 28, -1)
```

**Step 2: 取前 10 筆（使用 TAKE）**
```excel
=TAKE(
    SORT(訂單明細!A2:AN1001, 28, -1),
    10
)
```

**解釋：**
- `TAKE(array, num_rows)`：取前 N 列
- `TAKE(array, -10)`：取後 10 列

---

### 組合模式 3：條件 Top N

**情境：** 找出「電腦周邊類別」中「訂單總額 Top 5」

```excel
=TAKE(
    SORT(
        FILTER(訂單明細!A2:AN1001, 訂單明細!N2:N1001="電腦周邊"),
        28,
        -1
    ),
    5
)
```

**執行順序：**
1. FILTER：篩選「電腦周邊」
2. SORT：按金額降序
3. TAKE：取前 5 筆

---

### 組合模式 4：多條件篩選 + 多欄排序

**情境：** 找出「鑽石會員」的「已完成」訂單，先按類別、再按金額降序

```excel
=SORT(
    FILTER(
        訂單明細!A2:AN1001,
        (訂單明細!K2:K1001="鑽石") * (訂單明細!D2:D1001="已完成")
    ),
    {14, 28},
    {1, -1}
)
```

---

### 組合模式 5：UNIQUE + SORT

**情境：** 列出所有「產品類別」，並按字母順序排列

```excel
=SORT(UNIQUE(訂單明細!N2:N1001))
```

**解釋：**
- `UNIQUE()`：取得不重複的類別
- `SORT()`：按字母順序排列

### 作業 1：建立動態排行榜

**需求：** 在新工作表建立可切換的排行榜

**介面設計：**
```
A1: 排名依據     B1: [下拉選單: 訂單總額/購買數量]
A2: 排序方式     B2: [下拉選單: 降序/升序]
A3: 顯示筆數     B3: [輸入框: 10]

A5: [排行榜結果從這裡開始]
```

**公式（A5）：**
```excel
=LET(
    全部訂單, 訂單明細!A2:AN1001,
    排序欄位, IF(B1="訂單總額", 28, 19),
    排序方向, IF(B2="降序", -1, 1),
    顯示筆數, B3,
    TAKE(
        SORT(全部訂單, 排序欄位, 排序方向),
        顯示筆數
    )
)
```

### 🎓 Excel → Python 對照

| Excel 功能 | Python pandas 對應 |
|-----------|-------------------|
| `=SORT(A:Z, 3, -1)` | `df.sort_values('欄位名', ascending=False)` |
| `=SORT(A:Z, {3,5}, {1,-1})` | `df.sort_values(['欄3','欄5'], ascending=[True,False])` |
| `=SORTBY(A:Z, X:X, -1)` | `df.sort_values('X欄', ascending=False)` |
| `=TAKE(SORT(...), 10)` | `df.sort_values(...).head(10)` |
| `=TAKE(SORT(...), -10)` | `df.sort_values(...).tail(10)` |

### 常見錯誤

**錯誤 1：欄位編號錯誤**
```excel
❌ =SORT(A2:Z100, "訂單總額", -1)  // 錯誤：不能用欄位名
✅ =SORT(A2:Z100, 26, -1)          // 正確：使用欄位編號
```

**錯誤 2：陣列語法錯誤**
```excel
❌ =SORT(A2:Z100, 3, 5, 1, -1)     // 錯誤：參數順序錯誤
✅ =SORT(A2:Z100, {3,5}, {1,-1})   // 正確：使用大括號
```

**錯誤 3：SORTBY 缺少排序依據**
```excel
❌ =SORTBY(A2:Z100, -1)            // 錯誤：缺少 by_array
✅ =SORTBY(A2:Z100, AB2:AB100, -1) // 正確：指定排序依據
```
