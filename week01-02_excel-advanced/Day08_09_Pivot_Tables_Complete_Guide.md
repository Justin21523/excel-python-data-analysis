## 🎯 樞紐分析表核心概念

### **什麼是樞紐分析表？**

樞紐分析表（Pivot Table）是 Excel 最強大的資料分析工具，能快速：
- 彙總大量資料
- 多維度交叉分析
- 動態調整分析角度
- 自動計算統計值

### **四大區域**

```
┌─────────────────────────────────────┐
│ 篩選 (Filters)                      │
│ 頁面級別的篩選條件                   │
├──────────────┬──────────────────────┤
│              │ 欄 (Columns)         │
│              │ 橫向分組             │
│ 列 (Rows)    ├──────────────────────┤
│ 縱向分組     │ 值 (Values)          │
│              │ 要計算的數值         │
└──────────────┴──────────────────────┘
```

### **練習 1：建立第一個樞紐分析表**

**目標：** 計算每個產品類別的總銷售額

**步驟：**

1. **選擇資料範圍**
   - 點選 case01 中「訂單明細」工作表的任一儲存格
   - 確保資料有標題列

2. **插入樞紐分析表**

   - 目標：新工作表

3. **設定樞紐分析表**
   - 將「產品類別」拖曳到 **列** 區域

## 📊 Part 2: 計算欄位（2 小時）

### **練習 4：建立「平均客單價」計算欄位**

**目標：** 建立自訂計算欄位

**步驟：**

1. 點選樞紐分析表的任一儲存格
2. **樞紐分析表分析 → 欄位、項目與集 → 計算欄位**
3. 名稱：`平均客單價`
4. 公式：`= 訂單總額 / 訂單編號`
   - 訂單總額會自動加總
   - 訂單編號會自動計數
5. 點選「新增」→「確定」

**結果：**
新欄位會自動出現在值區域

**⚠️ 注意：**
- 計算欄位是基於彙總後的值
- 不是逐列計算後再彙總
- 適合總計級別的計算

---

### **練習 5：建立「毛利」計算欄位**

**假設：** 毛利率 = 30%

**公式：**
```
= 訂單總額 * 0.3
```

**步驟：**
1. 計算欄位 → 名稱：`毛利`
2. 公式：`= 訂單總額 * 0.3`
3. 新增

---

### **練習 6：建立「完成率」計算欄位**

**目標：** 已完成訂單佔比

**公式：**
```
= 已完成訂單數 / 總訂單數
```

**步驟比較複雜，需要兩步：**

1. **先建立「已完成數」計算項目**
   - 在「訂單狀態」欄位 → 右鍵 → 欄位設定
   - 計算項目 → 新增
   - 名稱：`已完成數`
   - 公式：`= IF(訂單狀態="已完成", 1, 0)`

2. **再建立「完成率」計算欄位**
   - 公式：`= 已完成數 / 訂單編號`

**或使用更簡單的方法：**
- 直接在樞紐分析表外計算
- 使用 GETPIVOTDATA 函數引用樞紐值

## 📊 Part 4: 分組功能（1.5 小時）

### **練習 11：日期分組**

**情境：** 將每日資料分組為月度、季度、年度

**步驟：**

1. 建立樞紐表：列 = 訂單日期，值 = 訂單總額
2. 右鍵點擊任一日期 → **群組**
3. 選擇分組單位：
   - ☑ 月
   - ☑ 季
   - ☑ 年

**結果：** 自動產生階層式日期分組

**可以展開/收合：**
```
▼ 2024
  ▼ 第 3 季
    ▶ 7月  (2,100,000)
    ▶ 8月  (1,950,000)
    ▶ 9月  (2,300,000)
  ▼ 第 4 季
    ▶ 10月 (2,450,000)
    ▶ 11月 (2,800,000)
```

**Python 對照：**
```python
df['年'] = df['訂單日期'].dt.year
df['季'] = df['訂單日期'].dt.quarter
df['月'] = df['訂單日期'].dt.month
df.groupby(['年', '季', '月'])['訂單總額'].sum()
```

## 💡 樞紐分析表最佳實踐

### **DO ✅**
- ✅ 資料源使用「表格」格式（插入 → 表格）
- ✅ 定期重新整理樞紐表（右鍵 → 重新整理）
- ✅ 為樞紐表取有意義的名稱
- ✅ 使用 Slicers 而非手動篩選
- ✅ 設定數值格式（千分位、小數位）

### **DON'T ❌**
- ❌ 在資料源中有空白列或欄
- ❌ 在樞紐表中直接修改數值（會被覆蓋）
- ❌ 過度複雜的計算欄位（改用外部輔助欄）
- ❌ 在同一工作表放太多樞紐表（會很亂）
