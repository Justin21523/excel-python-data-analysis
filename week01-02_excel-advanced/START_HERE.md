## 📝 Day 1 練習題摘要

### **基礎練習（3 題）**

**練習 1：篩選已完成訂單**
```excel
=FILTER(訂單明細!A2:AN1001, 訂單明細!D2:D1001="已完成")
```

**練習 2：篩選大額訂單（>10000）**
```excel
=FILTER(訂單明細!A2:AN1001, 訂單明細!AB2:AB1001>10000)
```

**練習 3：篩選 Apple 產品**
```excel
=FILTER(訂單明細!A2:AN1001, ISNUMBER(SEARCH("Apple", 訂單明細!O2:O1001)))
```

### **進階練習（4 題）**

**練習 4：AND 條件（已完成 + 金額>5000）**
```excel
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!D2:D1001="已完成") * (訂單明細!AB2:AB1001>5000)
)
```

**練習 5：OR 條件（電腦周邊 或 手機配件）**
```excel
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!N2:N1001="電腦周邊") + (訂單明細!N2:N1001="手機配件")
)
```

**練習 6：日期範圍（2024 年 11 月）**
```excel
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!B2:B1001>=DATE(2024,11,1)) *
    (訂單明細!B2:B1001<=DATE(2024,11,30))
)
```

**練習 7：複雜組合（4 個條件）**
```excel
=FILTER(
    訂單明細!A2:AN1001,
    (訂單明細!F2:F1001="北部") *
    ((訂單明細!Y2:Y1001="金卡") + (訂單明細!Y2:Y1001="白金")) *
    (訂單明細!D2:D1001="已完成") *
    (訂單明細!AB2:AB1001>3000)
)
```

### **高階挑戰（3 題）**

**練習 8：處理空值**
```excel
=FILTER(
    訂單明細!A2:AN1001,
    訂單明細!Y2:Y1001="白金",
    "查無白金會員訂單"
)
```

**練習 9：使用 LET 函數**
```excel
=LET(
    付款方式, "信用卡",
    最低金額, 5000,
    最高金額, 20000,
    資料範圍, 訂單明細!A2:AN1001,
    FILTER(
        資料範圍,
        (訂單明細!H2:H1001=付款方式) *
        (訂單明細!AB2:AB1001>=最低金額) *
        (訂單明細!AB2:AB1001<=最高金額)
    )
)
```

**練習 10：FILTER + SORT 組合（Top 10）**
```excel
=TAKE(
    SORT(
        FILTER(訂單明細!A2:AN1001, 訂單明細!N2:N1001="電腦周邊"),
        28, -1
    ),
    10
)
```

## 🎯 實戰專案：動態訂單查詢儀表板

**目標：** 建立可以根據不同條件組合查詢訂單的系統

**步驟摘要：**

1. **建立參數設定區**（新工作表）
   - 訂單狀態、日期範圍、金額範圍、產品類別

2. **建立查詢公式**
   ```excel
   =LET(
       訂單狀態, 查詢設定!B2,
       開始日期, 查詢設定!B3,
       結束日期, 查詢設定!B4,
       最低金額, 查詢設定!B5,
       最高金額, 查詢設定!B6,
       產品類別, 查詢設定!B7,

       SORT(
           FILTER(
               訂單明細!A2:AN1001,
               (訂單明細!D2:D1001=訂單狀態) *
               (訂單明細!B2:B1001>=開始日期) *
               (訂單明細!B2:B1001<=結束日期) *
               (訂單明細!AB2:AB1001>=最低金額) *
               (訂單明細!AB2:AB1001<=最高金額) *
               (訂單明細!N2:N1001=產品類別),
               "查無符合條件的訂單"
           ),
           28, -1
       )
   )
   ```

### **Q1: 我找不到練習資料檔案？**


### **Q2: 公式出現 #CALC! 錯誤？**

**A:** 檢查範圍行數是否一致
```excel
// ❌ 錯誤（行數不一致）
=FILTER(A2:AN1001, D2:D1000)

// ✅ 正確（行數一致）
=FILTER(A2:AN1001, D2:D1001)
```

### **Q3: 公式出現 #SPILL! 錯誤？**

**A:** 結果溢出範圍被佔用
- 清空公式下方和右方的儲存格
- 確保有足夠空間顯示結果

### **Q4: 篩選沒有結果？**

**A:** 可能原因：
1. 條件不正確（檢查字串、數字格式）
2. 確實沒有符合的資料
3. 使用 `if_empty` 參數確認

### **Q5: 公式太長看不懂？**

**A:** 使用 LET 函數拆分
```excel
=LET(
    資料, 訂單明細!A2:AN1001,
    條件1, 訂單明細!D2:D1001="已完成",
    條件2, 訂單明細!AB2:AB1001>5000,
    FILTER(資料, 條件1 * 條件2)
)
```
