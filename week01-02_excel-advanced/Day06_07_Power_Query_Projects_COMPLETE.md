# 🎯 Power Query 核心概念

## 什麼是 Power Query？

**定義：** Excel 內建的 ETL（Extract-Transform-Load）工具

**特色：**
- 🔄 步驟化轉換（每個操作都是一個步驟）
- 🔁 可重複執行（資料更新後，點一下「重新整理」即可）
- 🚫 不修改原始資料（轉換結果存在新表）
- 📝 自動產生 M 語言代碼

---

## Power Query 介面說明

```
┌─────────────────────────────────────────────────────────┐
│ 左側：查詢清單           │ 中間：資料預覽               │
│ - 查詢1                  │ ┌───┬───┬───┐               │
│ - 查詢2                  │ │A  │B  │C  │               │
│ - 查詢3                  │ ├───┼───┼───┤               │
│                          │ │1  │2  │3  │               │
└──────────────────────────┴─────────────────────────────┘
┌─────────────────────────────────────────────────────────┐
│ 右側：已套用的步驟                                       │
│ 1. 來源                                                 │
│ 2. 已變更類型                                           │
│ 3. 已移除欄位                                           │
│ 4. 已篩選列                                             │
│ ...                                                     │
└─────────────────────────────────────────────────────────┘
```

**重要按鈕：**
- **關閉並載入** - 完成編輯，載入到 Excel
- **重新整理** - 重新執行所有步驟
- **進階編輯器** - 查看/編輯 M 語言代碼

## Power Query 實作步驟

### **步驟 4：提取分店名稱**

目前資料沒有「分店」欄位，我們需要從檔案名稱提取。

1. **在步驟窗格中，找到「來源」步驟，點擊它**
2. 你會看到原始的檔案清單，包含「Name」欄位
3. 點擊「Name」欄位 → **新增欄位 → 從範例**

1. 選擇「Name」欄位

```m
= Text.BeforeDelimiter([Name], "分店")

```

**快捷鍵：**
- 選擇欄位 → 點擊欄位名稱左側的圖示 → 選擇類型

### **步驟 7：載入到 Excel**

1. **常用 → 關閉並載入**

# 📊 Project 3: 多表 Merge 合併（2 小時）

## 情境說明

你有 3 張表格需要合併：
1. **訂單表** - 訂單編號、客戶ID、產品SKU、數量
2. **客戶表** - 客戶ID、客戶姓名、電話、地址
3. **產品表** - 產品SKU、產品名稱、單價、類別

目標：建立完整的訂單明細表（包含客戶資訊和產品資訊）

---

## Merge 操作類型

| 類型 | 說明 | SQL 對照 | 使用時機 |
|------|------|---------|---------|
| **Left Outer** | 保留左表所有列 | LEFT JOIN | 最常用 |
| **Right Outer** | 保留右表所有列 | RIGHT JOIN | 少用 |
| **Inner** | 只保留匹配列 | INNER JOIN | 嚴格匹配 |
| **Full Outer** | 保留兩表所有列 | FULL OUTER JOIN | 檢查不匹配 |
| **Left Anti** | 只保留左表不匹配列 | 用於找缺失 |
| **Right Anti** | 只保留右表不匹配列 | 用於找缺失 |

---

## 實作步驟

### **步驟 1：載入三張表**

1. 將三張表載入 Power Query
2. 不要立即「關閉並載入」，先保留在 Power Query 編輯器中

---

### **步驟 2：合併訂單表 + 客戶表**

1. 選擇「訂單表」查詢
2. **常用 → 合併查詢**
3. 設定：
   - 選擇「客戶表」
   - 匹配欄位：訂單表的「客戶ID」= 客戶表的「客戶ID」
   - 聯結類型：**Left Outer**
4. 點選「確定」

---

### **步驟 3：展開客戶資訊**

1. 新增的「客戶表」欄位右側有 ↔️ 圖示
2. 點擊 → 選擇要顯示的欄位：
   - ✅ 客戶姓名
   - ✅ 電話
   - ✅ 地址
   - ❌ 取消勾選「使用原始欄位名稱作為前置詞」
3. 點選「確定」

**結果：** 訂單表現在包含客戶姓名、電話、地址欄位！

**Python 對照：**
```python
df_merged = df_orders.merge(
    df_customers[['客戶ID', '客戶姓名', '電話', '地址']],
    on='客戶ID',
    how='left'
)
```

---

### **步驟 4：再次合併產品表**

1. **常用 → 合併查詢**
2. 設定：
   - 選擇「產品表」
   - 匹配欄位：「產品SKU」= 「產品SKU」
   - 聯結類型：**Left Outer**
3. 展開產品資訊：
   - ✅ 產品名稱
   - ✅ 單價

df_final = df_merged.merge(

# 📊 Project 4: Unpivot/Pivot 轉換（2 小時）

## 情境 1：Unpivot（寬表 → 長表）

### **問題資料（寬格式）：**

| 產品 | 1月 | 2月 | 3月 |
|------|-----|-----|-----|
| 產品A | 100 | 150 | 200 |
| 產品B | 80 | 90 | 110 |
| 產品C | 120 | 130 | 140 |

### **目標格式（長格式）：**

| 產品 | 月份 | 銷售額 |
|------|------|--------|
| 產品A | 1月 | 100 |
| 產品A | 2月 | 150 |
| 產品A | 3月 | 200 |
| 產品B | 1月 | 80 |
| ... | ... | ... |

---

### **Unpivot 操作步驟**

1. 載入資料到 Power Query
2. 選擇「產品」欄位（這是 ID 欄位，不要 unpivot）
3. **轉換 → 取消樞紐其他欄位**
4. Power Query 自動將「1月、2月、3月」轉為長格式
5. 重新命名：
   - 「屬性」→ 「月份」
   - 「值」→ 「銷售額」

**Python 對照：**
```python
df_long = pd.melt(
    df_wide,
    id_vars=['產品'],
    var_name='月份',
    value_name='銷售額'
)
```

---

df_wide = df_long.pivot_table(

     - 總銷售額 = 加總「訂單總額」
     - 平均客單價 = 平均「訂單總額」
     - 客戶數 = 計算相異「客戶ID」

**Python 對照：**
```python
daily_summary = df.groupby('訂單日期').agg({
    '訂單編號': 'count',
    '訂單總額': ['sum', 'mean'],
    '客戶ID': 'nunique'
})
```
