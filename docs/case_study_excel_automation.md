# Case Study: Excel Automation

## Problem

Business users need Excel reports that are formatted, shareable, and easy to inspect without running Python.

## Dataset

Retail sample workbook with orders, order items, customers, products, and inventory sheets.

## Approach

Use openpyxl to build formatted workbook outputs and a dedicated feature showcase workbook.

## Key Techniques

- formulas
- named styles
- conditional formatting
- comments and hyperlinks
- data validation
- worksheet protection
- charts
- freeze panes and filters

## Output

- `reports/portfolio_excel_analysis_report.xlsx`
- `reports/openpyxl_feature_showcase.xlsx`

## Screenshots

See `assets/screenshots/report_export.png`.

## What This Demonstrates

The project can produce Excel artifacts for business stakeholders, not just Python-only analysis.
