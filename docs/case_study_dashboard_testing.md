# Case Study: Dashboard Testing

## Problem

Interactive dashboards can break silently when pages, buttons, session state, or charts change.

## Dataset

Retail demo workbook generated by the project.

## Approach

Use Playwright to run the complete demo flow and produce verification artifacts.

## Key Techniques

- automatic Streamlit startup
- page navigation
- button clicks
- download button checks
- KPI and chart text checks
- screenshots
- video recording
- Playwright trace
- HTML report generation

## Output

- `scripts/verify_ui.py`
- `scripts/run_e2e_demo.py`
- `tests/e2e/test_dashboard_demo.py`
- `assets/demo/demo_walkthrough.mp4`
- `assets/demo/demo_steps.gif`

## Screenshots

See `assets/screenshots/home_dashboard.png` and `assets/screenshots/business_analytics.png`.

The project includes automated UI validation, not only unit tests.
