# Case Study: Data Quality Pipeline

## Problem

Excel workbooks often contain missing values, duplicate rows, inconsistent categories, invalid dates, and mixed numeric formats.

## Dataset

Retail workbook and messy sales workbook.

## Approach

Profile every dataset before analysis and apply reusable cleaning operations.

## Key Techniques

- multi-sheet Excel ingestion
- schema detection
- quality issue detection
- missing value summaries
- duplicate detection
- text normalization
- date conversion
- currency and percentage parsing

## Output

- quality score
- issue table
- before/after cleaning preview
- cleaned workbook export
